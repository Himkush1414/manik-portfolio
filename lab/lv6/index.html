The Stack for

Approach

Built to be
Read Later

I optimise for the person who opens the file a year from now — clear names, small functions, control flow with no surprises. The clever one-liner rarely survives that test.

Process

Shipped in
Small Steps

Changes go out behind flags, reviewed and easy to roll back. Ten quiet deploys in a day beat one nervous release a month, and the history stays readable.

Craft

Judged by
How It Feels

Performance budgets, real-device checks, motion that holds the frame rate. It is done when it loads fast, answers instantly, and stays out of your way.

I design and build for the web. Interfaces, tools, small worlds — things that answer the moment you touch them. To me, code and design are one craft: decide what matters, remove the rest, and make what is left feel inevitable.
